# KHAIPUI — Mockup เว็บขายปุ๋ยและอุปกรณ์การเกษตร

Mockup แบบ static HTML (ไม่มี build step) เปิดไฟล์ในเบราว์เซอร์ได้ทันที

| ไฟล์ | หน้า |
| --- | --- |
| `index.html` | หน้าแรก (Desktop, responsive) |
| `product.html` | หน้ารายละเอียดสินค้า — ปุ๋ยเคมี สูตร 16-16-16 |
| `cart.html` | ตะกร้าสินค้า + สรุปคำสั่งซื้อ + โค้ดส่วนลด |
| `checkout.html` | จัดส่งและชำระเงิน (ข้อมูลผู้รับ, ที่อยู่, วิธีจัดส่ง, วิธีชำระเงิน) |
| `mobile.html` | หน้าแรกเวอร์ชันมือถือ (390px) |

ลำดับการกด: หน้าแรก → หน้าสินค้า → ตะกร้า → ชำระเงิน

## โทนการออกแบบ

- สีหลัก: เขียวเข้ม `#1E5631` / `#143D22`, พื้นเขียวอ่อน `#EEF3EC`
- สีเน้น (ปุ่มซื้อ): เหลืองเก็บเกี่ยว `#F5B700`
- ฟอนต์: Noto Sans Thai จาก Google Fonts
- โลโก้: ไอคอน `sprout` จาก [Lucide](https://lucide.dev/icons/sprout) (ISC license)

## ข้อมูลที่ต้องเติม

ข้อความในวงเล็บเหลี่ยมเป็นช่องว่างให้ใส่ข้อมูลจริง เช่น `฿[ราคา]`, `[เบอร์โทร]`,
`LINE @[ไอดีไลน์]`, `[เลขทะเบียน]`, `[อัตรา] กก./ไร่`

ตารางสูตรปุ๋ยตามระยะของข้าวในหน้าแรกเป็นเพียงตัวอย่าง ควรให้นักวิชาการเกษตรตรวจสอบก่อนใช้จริง
